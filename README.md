## O que preciso para começar

Para que o prazo seja cumprido, o cliente precisa enviar **antes do início**:

1. **Briefing completo** (nome do negócio, nicho, objetivo, tom de voz, serviços, WhatsApp real).
2. **Logo** em alta resolução (PNG ou SVG) e, se tiver, manual de marca.
3. **Textos** prontos ou aprovação do texto proposto.
4. **Imagens** que deseja usar (ou autorização para uso de banco de imagens).
5. **Acessos necessários** (ex: conta Google para Analytics, número do WhatsApp Business, credenciais de API).
6. **Pagamento confirmado** (50% na aprovação, 50% na entrega — ou 100% antecipado para valores abaixo de R$ 300).
